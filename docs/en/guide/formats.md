# Dedicated File Formats

To act on the design philosophy of **Resume = Information + Template**, Fix Resume has designed three unique file formats for processing your resume locally and in the cloud. These formats ensure that data modification and layout changes do not interfere with each other.

<h2>
  <div class="flex align-center gap-2">
    <img src="/FRI.ico" width="32" />
    <span>1. FRI Format (Fix Resume Information)</span>
  </div>
</h2>

The FRI file is the "soul" and "database" of your resume.
- **Role**: fully saves your objective personal background information (e.g., name, contact, education, project outlines, work details, etc.).
- **Features**: purely contains business data, **without any layout or styling information**.
- **Advantage**: it is an asset that grows with your career. A detailed and complete FRI file can derive countless job-seeking resumes with different focuses.

<h2>
  <div class="flex align-center gap-2">
    <img src="/FRT.ico" width="32" />
    <span>2. FRT Format (Fix Resume Template)</span>
  </div>
</h2>

The FRT file is the "clothing" that controls the visual presentation of the resume.
- **Role**: essentially saves view configurations like how templates and components are arranged, layout dimensions, and theme colors.
- **Features**: built into the platform or customized and imported by you. It dictates how a work experience should be aligned and what font to use.
- **Advantage**: you can freely switch between different FRTs in different periods or when interviewing for different companies without having to re-enter basic data.

<h2>
  <div class="flex align-center gap-2">
    <img src="/FRR.ico" width="32" />
    <span>3. FRR Format (Fix Resume Render)</span>
  </div>
</h2>

The FRR file is the "crystallization" formed by combining "data" and "templates".
- **Role**: the final rendered page information set generated by combining the two products above (FRI and FRT).
- **Features**: this is the true configuration file used for display or printing/exporting to PDF. It solidifies the content and appearance adopted for a specific delivery.
- **Advantage**: you can save every specific FRR as a historical version for backtracking, with no worry about losing the version snapshot delivered to a specific company due to modifying the current resume.
