# Clients and Platforms

Fix Resume provides excellent multi-platform support, letting you take control of your resume data wherever you are.

## Web Application
The web version works out of the box, eliminating any installation process. All features are available within the browser, and we ensure that data is processed and saved in your local environment.
- **URL**: [https://fix.my-resume.space](https://fix.my-resume.space)
- **Best for**: trying it out for the first time, quickly tweaking an experience detail, or sharing results.

## Database Storage Options

You can freely choose your preferred data storage method in the platform **"Settings"**. We offer entirely offline local solutions alongside cross-platform cloud solutions.

### Web Application Storage
The web version supports the following storage types:
- **IndexedDB / OPFS (Origin Private File System)**: The default option. No login required, entirely free. Your data is absolutely safe and stored strictly in your current browser's offline environment.
  - *Note*: It does not support cross-browser or cross-device data syncing. However, it provides powerful import/export capabilities. You can export information, templates, or resumes individually as JSON (or `.fri`, `.frt`, `.frr` files) at any time, or trigger a full 1-click backup in settings.
- **Cloud Database (Pro Plan)**: The advanced option. Unlocked by logging in and subscribing to the Pro plan. Data is securely encrypted and stored in the cloud, achieving seamless cross-browser and cross-device synchronization. Also unlocks advanced features like online resume sharing and visitor tracking.

### Desktop Client Storage
The desktop client builds upon cloud services by offering deeper local integration:
- **Local FS (File System)**: The default option. All data is saved directly as real files in a designated directory on your local hard drive. Fully supports the same individual imports/exports and complete system backups as the web version.
- **Cloud Database (Pro Plan)**: Identical to the web experience; sync across multiple devices and unlock premium online sharing capabilities upon subscription.
