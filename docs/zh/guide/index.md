欢迎来到 **扉客司 (fix resume)** 的使用指南。

## 核心宗旨：简历 = 数据信息 + 模版
传统写简历的方式总是将排版和内容混为一谈，导致每次想换个样式，都需要重新排版一次，甚至需要重新输入内容。

扉客司的核心宗旨是：**`resume = information + template`**

我们将数据与样式彻底解耦。使用扉客司，您只需要专注两件事：
1. **建立您的履历信息库**：详尽地记录您的教育、工作、项目等数据。
2. **挑选并组合模板**：选择我们提供的各种精美模板。

扉客司会自动将您的信息灌入模板中，瞬间生成专业且排版精良的简历。

## 基本使用流程

- **第一步：建立个人履历 (数据信息)**
  - 在客户端中录入你的个人基础信息、工作经历、项目经验等，形成完整的“数据库”。
- **第二步：挑选心仪模版 (模版)**
  - 在模板市场挑选你喜欢的样式，或者利用高度自定义功能调整属于你的风格。
- **第三步：一键生成与微调**
  - 结合信息和模版，生成简历。您可以针对具体的岗位，在生成时微调履历内容，而不影响基础数据。
