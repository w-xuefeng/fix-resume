# 专属文件格式解析

为了践行 **简历 = 数据信息 + 模版** 的设计哲学，扉客司为您在本地及云端处理简历时设计了三种独特的文件格式生态。这些格式保证了信息修改与版式变更互不干扰。

<h2>
  <div class="flex align-center gap-2">
    <img src="/FRI.ico" width="32" />
    <span>1. FRI 格式 (Fix Resume Information)</span>
  </div>
</h2>

FRI 文件是您简历的“灵魂”和“数据库”。
- **作用**：全量保存着您个人的客观履历信息体系（例如：姓名联系方式、教育经历、项目经验大纲、工作经历细节等）。
- **特点**：里面纯粹只包含业务数据，**绝不带有任何排版或样式信息**。
- **优势**：它是一份可以随着你职业生涯不断增加的资产，一份详尽完善的 FRI 文件可以衍生出无数个不同侧重点的求职简历。

<h2>
  <div class="flex align-center gap-2">
    <img src="/FRT.ico" width="32" /> 
    <span>2. FRT 格式 (Fix Resume Template)</span>
  </div>
</h2>

FRT 文件是掌控简历视觉展现的“外衣”。
- **作用**：本质上保存着简历样板和组件如何排列、如何定版、主题色是什么等视图表现配置。
- **特点**：由平台内建或是您可以自定义导入的文件。它决定了一份工作经历在这里应该怎么对齐，采用什么字体。
- **优势**：你可以在不同时期或面试不同企业时，自由切换各类 FRT 而无须重新去输入基础资料。

<h2>
  <div class="flex align-center gap-2">
    <img src="/FRR.ico" width="32" />
    <span>3. FRR 格式 (Fix Resume Render)</span>
  </div>
</h2>

FRR 文件是“数据”和“模板”碰撞结合后的“结晶”。
- **作用**：由上述的两种产物（FRI 和 FRT）互相组合生成的最终渲染态页面信息集合。
- **特点**：这是真正意义上用于展示或打印导出为 PDF 格式的具体简历配置档。它固化了某次特定投递下采用的内容和样貌。
- **优势**：您可以保存每一个特定的 FRR 作为历史版本追溯，无需担心改动了当前履历而丢失了上一次投递特定公司的版本快照。
